## 稿件格式（每章一个 Markdown 文件）

文件名以章节序号开头：`00-序.md`、`01-论十干十二支.md`……序号与原文章节一一对应（序为 00）。

```markdown
# 一、论十干十二支

> 原文一段（可以把一个长段落拆成几段分别对照）

白话译文。可以有多个自然段。

（译注：校勘或补充说明。）

![图的简短说明](figs/01-xxx.svg)

*图 1-1　图的说明。（译者补绘，原书无此图）*
```

- `>` 引用块是**原文**，必须与 `content/sources/` 底本逐字一致（只允许拆段，不允许改字）；构建时会校验，讹字在译注里说明。
- 引用块之后、下一个引用块之前的普通段落是这段原文的**白话**。
- 图片与紧随其后的斜体段落是**补图**及其说明；凡原书没有的图，说明里须注明“译者补绘，原书无此图”。
- 补图由 `node scripts/translation-figs.mjs` 生成到 `figs/`，配色随网站主题；在 GitHub 上直接查看时使用浅色后备色。

### 标题、命例与注疏（穷通宝鉴、滴天髓）

```markdown
## 正月丙火

正月的丙火            ← 紧跟标题的普通段落是标题的白话（可省略）

> 【命例】丙午 庚寅 丙午 庚寅 ｜ 状元
> 【命例】甲子 丙寅 甲子 丙寅 ｜ 大运：丁卯 戊辰 己巳 ｜ 女命
> 【原文】滴天髓本文（韵文）
> 【原注】原注
> 【任氏曰】任铁樵增注
```

- `##`/`###` 标题、`【原文】`、`【原注】`、`【任氏曰】` 须与底本逐块对应；命例的四柱、大运、标注须与底本完全一致。
- 原文、原注、任氏曰与普通段落都必须有白话；标题和命例的白话可省略。

`npm run build:books` 会把译稿合并进 `src/content/books/<书>.json`，站内阅读器提供“原文 / 对照 / 白话”三种阅读方式。
